# What Is an Operating System?

An **operating system (OS)** is system software that manages communication between computer hardware and applications.

It acts as a **mediator between software and hardware**, allowing applications to use system resources without needing to understand the underlying hardware details.

Examples of operating systems include:

- Windows
- macOS
- Linux
- Android
- iOS

Operating systems are used on many different types of devices, including computers, smartphones, embedded systems, smart appliances, and other electronic devices.

---

## Why Do We Need an Operating System?

Different computers can have different hardware configurations, yet the same application can run on many of them.

The operating system provides a common interface between applications and hardware. Applications can request resources from the OS without directly managing the hardware themselves.

For example, when you run a web browser, the operating system manages access to:

- CPU resources
- Memory
- Storage
- Network resources
- Input and output devices

This abstraction allows applications to work without needing to know the specific hardware implementation of the computer.

---

## Functions of an Operating System

An operating system manages the computer's hardware and provides services to applications.

### 1. Resource Management

The OS manages and allocates system resources such as:

- CPU
- Memory
- Storage
- Network resources
- Peripheral devices

For example, you can run a browser, media player, and other applications simultaneously because the OS manages how system resources are shared between them.

### 2. Data Protection and Secure Access

The OS controls access to system resources and helps prevent applications or users from accessing resources they are not authorized to use.

### 3. Hardware and Peripheral Interaction

The OS provides a layer of abstraction between applications and hardware.

Applications do not normally need to know the specific details of how a particular hardware device works. Instead, they interact with the operating system, which communicates with the hardware.

### 4. File Management

The OS manages files and directories stored on storage devices.

It provides mechanisms for applications and users to create, read, modify, delete, and organize files.

### 5. Running Programs

The OS provides the environment required to start and manage applications.

It is responsible for allocating the resources applications need while they are running.

## Operating System as a Mediator

A useful way to understand an operating system is to think of it as a **mediator between applications and hardware**.

```text
Applications
     │
     ▼
Operating System
     │
     ▼
Hardware
````

For example:

```text
Web Browser
     │
     ▼
Operating System
     │
     ├── CPU
     ├── Memory
     ├── Storage
     ├── Network
     └── Peripherals
```

The application requests resources from the operating system rather than directly controlling the hardware.

## Components of an Operating System

An operating system consists of several important components. Two fundamental components are the **kernel** and the **user interface**.

---

## Kernel

The **kernel** is the core component of an operating system.

It manages communication between software and hardware and provides essential services required for applications to run.

The kernel is typically one of the first components loaded when the operating system starts.

Some of its responsibilities include:

- CPU management
- Memory management
- Process management
- Hardware interaction
- Device management
- Providing system-level services to applications

### Simplified Architecture

```text
Applications
     │
     ▼
Operating System
     │
     ▼
Kernel
     │
     ▼
Hardware
```

---

## User Interface

Users need a way to interact with the operating system. Two common interfaces are:

- **Graphical User Interface (GUI)**
- **Command-Line Interface (CLI)**

### Graphical User Interface (GUI)

A **GUI** allows users to interact with the operating system through graphical elements such as:

- Windows
- Icons
- Menus
- Buttons
- Dialog boxes

For example, the Windows desktop provides a GUI for interacting with the operating system.

### Command-Line Interface (CLI)

A **CLI** allows users to interact with the operating system by entering text-based commands into a terminal.

For example:

```bash
ls
```

The exact commands available depend on the operating system and shell being used.

> [!TIP]  
> CLI knowledge is particularly important for MLOps because many development, deployment, cloud, Docker, Kubernetes, and CI/CD workflows are performed through terminals.

# Types of Kernels

Two common kernel architectures are:

- **Monolithic kernels**
- **Microkernels**

## Monolithic Kernel

A **monolithic kernel** provides most operating system services within the kernel itself.

These services can include:

- Process management
- Memory management
- File systems
- Device drivers
- Network management

This approach can provide good performance because many operating system services operate within the same kernel space.

## Microkernel

A **microkernel** keeps the core kernel as small as possible.

Only essential functionality is kept inside the kernel, while additional services can run outside the kernel.

The architecture can be extended through additional components such as **device drivers** and other system services.

### Simplified Comparison

```text
Monolithic Kernel
```

```text

        ├── Device Drivers
        ├── Networking
        └── Other Services
```

# Key Takeaways

- An **operating system (OS)** is system software that manages communication between applications and hardware.
- The OS manages resources such as CPU, memory, storage, networks, and peripherals.
- It provides **abstraction**, allowing applications to interact with hardware without needing to understand its specific implementation.
- Major OS responsibilities include:
    - Resource management
    - Data protection and secure access
    - Hardware and peripheral interaction
    - File management
    - Program execution
- The **kernel** is the core component of an operating system.
- Users commonly interact with an OS through:
    - **GUI** — Graphical User Interface
    - **CLI** — Command-Line Interface
- Two common kernel architectures are **monolithic kernels** and **microkernels**.
- Understanding operating systems and CLI usage is particularly useful for **MLOps**, where Linux, terminals, containers, cloud infrastructure, and automation tools are commonly used.
