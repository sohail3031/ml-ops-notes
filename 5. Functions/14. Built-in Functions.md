## What is a Function?

A **function** is a reusable block of code that performs a specific task.

### Why use functions?

- Avoid repeating code.
- Make programs easier to read.
- Make programs easier to maintain.
- Can be called multiple times with different arguments.

Example:

```python
multiply(1, 7)
```

- `multiply` → function name
- `1`, `7` → arguments

---

# Calling (Invoking) a Function

To call a function:

```python
function_name(arguments)
```

Example:

```python
print("Hello, world!")
```

---

# The `print()` Function

`print()` is one of Python's built-in functions.

Examples:

```python
print("Hello, world!")

print()

print("Bye,", "then!")
```

Output:

```text
Hello, world!

Bye, then!
```

`print()` can be used:

- with one argument
- with multiple arguments
- with no arguments (prints a blank line)

---

# Built-in Functions

Python provides many built-in functions that are always available.

Some common built-in functions include:

|Function|Purpose|
|---|---|
|`print()`|Display output|
|`input()`|Read user input|
|`len()`|Get length of an object|
|`type()`|Get data type|
|`int()`|Convert to integer|
|`float()`|Convert to float|
|`str()`|Convert to string|
|`sum()`|Add iterable values|
|`round()`|Round a number|
|`min()`|Smallest value|
|`max()`|Largest value|
|`help()`|Show documentation|

---

# `len()`

Returns the number of items in a container.

Example:

```python
number = "111"

print(len(number))
```

Output:

```text
3
```

Works with:

- Strings
- Lists
- Tuples
- Ranges
- Other sequences

---

# Type Conversion Functions

Convert between data types.

## Convert to Integer

```python
number = "111"

integer = int(number)

print(integer)
```

Output:

```text
111
```

---

## Convert to Float

```python
number = "111"

floating = float(number)

print(floating)
```

Output:

```text
111.0
```

---

## Convert to String

```python
value = 25

text = str(value)

print(text)
```

Output:

```text
25
```

---

# `sum()`

Adds all values in an iterable.

Example:

```python
integer = 111
floating = 111.0

total = sum((integer, floating))

print(total)
```

Output:

```text
222.0
```

> **Note:** `sum()` expects an iterable such as a list or tuple.

---

# `round()`

Rounds a floating-point number.

Example:

```python
value = 222.0

print(round(value))
```

Output:

```text
222
```

Example:

```python
print(round(3.7))
```

Output:

```text
4
```

---

# `min()` and `max()`

Return the smallest and largest values.

Example:

```python
a = 3
b = 5.4
c = a + b

print(min(a, b))
print(max(a, b, c))
```

Output:

```text
3
8.4
```

---

# `type()`

Returns the data type of a value.

Example:

```python
print(type(10))
print(type(3.14))
print(type("Hello"))
```

Output:

```python
<class 'int'>
<class 'float'>
<class 'str'>
```

---

# `help()`

Displays documentation for a function.

Example:

```python
help(len)
```

Output (simplified):

```python
Help on built-in function len

len(obj)

Return the number of items in a container.
```

Useful when:

- Learning a new function
- Unsure about function arguments
- Need documentation from Python itself

---

# Function Arguments

Arguments are values passed to a function.

Example:

```python
print("Hello")
```

`"Hello"` is an argument.

Multiple arguments:

```python
print("Python", "Programming")
```

Output:

```text
Python Programming
```

# Best Practices

- Use built-in functions instead of writing your own when possible.
- Read the documentation using `help()`.
- Choose descriptive names for your own functions.
- Reuse functions to reduce duplicated code.
