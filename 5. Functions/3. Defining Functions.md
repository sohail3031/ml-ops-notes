# Overview

Functions allow you to group reusable code into a single block that performs a specific task. Python provides many built-in functions (such as `print()` and `len()`), but often you'll need to create your own.

Creating functions makes your code:

- More organized
- More readable
- Easier to maintain
- Reusable

---

# Defining a Function

In Python, functions are defined using the `def` keyword (short for **define**).

## Syntax

```python
def function_name(parameter1, parameter2, ...):
    # Function body
    ...
    return value
```

### Components of a Function

- **`def`** — Keyword used to define a function.
- **Function name** — The name used to call the function later.
- **Parameters** — Variables that receive values when the function is called.
- **Colon (`:`)** — Marks the beginning of the function body.
- **Indentation** — The function body must be indented (typically 4 spaces).
- **`return`** — Sends a value back to the caller (optional).

> [!NOTE]
> Function names should follow the same naming convention as variables:
>
> - Use lowercase letters.
> - Separate words with underscores (`snake_case`).

---

# Function Example

```python
def multiply(x, y):
    return x * y
```

Calling the function:

```python
a = multiply(3, 5)
print(a)

b = multiply(a, 10)
print(b)
```

**Output**

```text
15
150
```

---

# Functions Without Parameters

A function does not have to accept any parameters.

```python
def welcome():
    print("Hello, people!")
```

Calling it:

```python
welcome()
```

**Output**

```text
Hello, people!
```

---

# Empty Functions

Sometimes you may want to create a function that you'll implement later.

Use the `pass` statement as a placeholder.

```python
def lazy_func(param):
    pass
```

Calling this function does nothing.

```python
lazy_func(10)
```

> [!TIP]
> `pass` is commonly used during development when planning a function but not implementing it yet.

# Parameters vs Arguments

Although the terms are often used interchangeably, they have different meanings.

| Parameter | Argument |
|-----------|----------|
| Defined in the function declaration | Passed when calling the function |
| Acts as a placeholder | The actual value supplied to the function |

---

## Example

```python
def send_postcard(address, message):
    print("Sending a postcard to", address)
    print("With the message:", message)
```

Calling the function:

```python
send_postcard("Hilton, 97", "Hello, bro!")

send_postcard("Piccadilly, London", "Hi, London!")
```

**Output**

```text
Sending a postcard to Hilton, 97
With the message: Hello, bro!

Sending a postcard to Piccadilly, London
With the message: Hi, London!
```

In this example:

- `address` and `message` are **parameters**.
- `"Hilton, 97"` and `"Hello, bro!"` are **arguments**.

---

# Passing the Correct Number of Arguments

A function must receive the required number of arguments.

```python
send_postcard("Big Ben, London")
```

**Output**

```text
TypeError: send_postcard() missing 1 required positional argument: 'message'
```

> [!WARNING]
> If a function expects two parameters, you must provide exactly two arguments unless default values are defined.

# Returning Values

Many functions calculate a value and return the result using the `return` keyword.

## Example

```python
def celsius_to_fahrenheit(temp_c):
    temp_f = temp_c * 9 / 5 + 32
    return round(temp_f, 2)
```

Calling the function:

```python
water_bp = celsius_to_fahrenheit(100)

print(water_bp)
```

**Output**

```text
212.0
```

> [!NOTE]
> `return` sends a value back to the caller. That returned value can be stored in a variable, printed, or used in another expression.

---

# Functions That Don't Return Anything

Not every function returns a value.

For example, `print()` performs an action but does **not** return anything.

```python
chant = print("We Will Rock You")

print(chant)
```

**Output**

```text
We Will Rock You
None
```

Here:

- `print("We Will Rock You")` displays text on the screen.
- Since `print()` has no return value, the variable `chant` stores `None`.

> [!IMPORTANT]
> In Python, if a function does not explicitly return a value, it automatically returns `None`.

---

# How `return` Affects Execution

When Python encounters a `return` statement, the function immediately stops executing.

```python
def example():
    print("First")
    return
    print("Second")
```

Calling the function:

```python
example()
```

**Output**

```text
First
```

The second `print()` is never executed.

---

# Multiple `return` Statements

A function may contain multiple `return` statements, but **only one of them executes**.

Execution stops as soon as the first applicable `return` statement is reached.

```python
def check_number(num):
    if num > 0:
        return "Positive"
    return "Zero or Negative"
```

---

# Key Takeaways

- Functions are defined using the `def` keyword.
- Function bodies must be properly indented.
- Parameters are placeholders defined in the function.
- Arguments are the actual values passed during a function call.
- A function can have:
  - No parameters
  - One parameter
  - Multiple parameters
- Use `pass` as a placeholder for an empty function.
- The `return` statement sends a value back to the caller.
- If no value is returned explicitly, Python returns `None`.
- Function execution stops immediately after a `return` statement.
- Functions improve code reusability, readability, and maintainability.
