# Overview

The `print()` function is one of Python's most commonly used built-in functions. It is primarily used to display output to the console.

Basic usage:

```python
number = 5

print(number)
```

**Output**

```text
5
```

While `print()` appears simple, it provides several useful keyword arguments that allow you to customize the output.

---

# Syntax

```python
print(*objects, sep=' ', end='\n')
```

### Parameters

| Parameter | Description | Default Value |
|-----------|-------------|---------------|
| `*objects` | One or more objects to print | Required |
| `sep` | Separator between objects | `' '` (space) |
| `end` | String appended after the output | `'\n'` (newline) |

---

# Printing Multiple Objects

You can print multiple objects by separating them with commas.

```python
print("Python", "is", "awesome")
```

**Output**

```text
Python is awesome
```

By default, the objects are separated by a single space.

---

# The `sep` Keyword Argument

The `sep` argument specifies the separator placed between multiple objects.

## Syntax

```python
print(object1, object2, ..., sep="separator")
```

---

## Example: Custom Separator

```python
print("Chip", "Dale", sep="&")
```

**Output**

```text
Chip&Dale
```

---

## Default Separator

The default value of `sep` is a space (`' '`).

```python
print("Gadget", "Hackwrench", sep=" ")
```

```python
print("Gadget", "Hackwrench")
```

**Output**

```text
Gadget Hackwrench
```

Both statements produce the same output.

---

## Empty Separator

An empty string removes the space between objects.

```python
print(13, "th", sep="")
```

**Output**

```text
13th
```

> [!TIP]
> `sep=""` is useful when you want to concatenate values without manually converting numbers to strings.

---

## Invalid `sep` Value

The `sep` argument must be either a string or `None`.

```python
print("Chip", "Dale", sep=0)
```

**Output**

```text
TypeError: sep must be None or a string, not int
```

> [!WARNING]
> Always provide a string as the separator.

---

# The `end` Keyword Argument

The `end` argument specifies what should be printed after the output.

By default, it is a newline character (`'\n'`), which moves the cursor to the next line.

---

## Default Behavior

```python
print("Monterey")
print()
print("Jack")
```

**Output**

```text
Monterey

Jack
```

Notice that `print()` without arguments simply prints a blank line.

---

## Custom `end`

You can replace the newline with any string.

```python
print("Tick-Tock", end=" the ")
print("Crocodile", end="!")
```

**Output**

```text
Tick-Tock the Crocodile!
```

---

## Printing on the Same Line

```python
print("Hello", end=" ")
print("World")
```

**Output**

```text
Hello World
```

---

# Unpacking Objects with `*`

Sometimes you want to print each element of a list separately instead of printing the entire list.

## Printing a List Normally

```python
characters = [
    "Humphrey the Bear",
    "Spike the Bee",
    "Fat Cat"
]

print(characters)
```

**Output**

```text
['Humphrey the Bear', 'Spike the Bee', 'Fat Cat']
```

---

## Unpacking a List

Using the `*` operator unpacks the list into individual arguments.

```python
characters = [
    "Humphrey the Bear",
    "Spike the Bee",
    "Fat Cat"
]

print(*characters)
```

**Output**

```text
Humphrey the Bear Spike the Bee Fat Cat
```

Python treats this as:

```python
print(
    "Humphrey the Bear",
    "Spike the Bee",
    "Fat Cat"
)
```

---

## Combining Unpacking with `sep`

You can combine unpacking with the `sep` argument.

```python
characters = ["Tom", "Jerry", "Spike"]

print(*characters, sep=", ")
```

**Output**

```text
Tom, Jerry, Spike
```

---

# Positional vs Keyword Arguments

The objects you want to print are **positional arguments**.

The customization options like `sep` and `end` are **keyword arguments**, meaning you must specify their names.

```python
print("Python", "Java", sep=" | ", end=".")
```

**Output**

```text
Python | Java.
```

---

# Common Use Cases

## Print Values Without Spaces

```python
print("Version", 3, ".", 12, sep="")
```

**Output**

```text
Version3.12
```

---

## Print Multiple Lines on One Line

```python
print("Hello", end=" ")
print("World", end="!")
```

**Output**

```text
Hello World!
```

---

## Print List Elements

```python
numbers = [1, 2, 3, 4, 5]

print(*numbers)
```

**Output**

```text
1 2 3 4 5
```

---

# Key Takeaways

- `print()` is used to display output to the console.
- It can print one or multiple objects.
- The default separator (`sep`) is a space.
- The default ending (`end`) is a newline (`\n`).
- Use `sep` to customize the separator between printed objects.
- Use `end` to control what appears after the output.
- The `*` operator unpacks iterable objects (such as lists) into separate arguments.
- `sep` and `end` are **keyword arguments** and must be specified by name.
- `print()` returns `None`; it only performs the action of displaying output.
