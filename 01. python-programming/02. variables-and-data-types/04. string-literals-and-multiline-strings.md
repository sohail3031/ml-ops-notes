# Overview

Strings are one of the most commonly used data types in Python. They are used to store textual data such as names, messages, file paths, and more.

A **string literal** is a sequence of characters enclosed within **single quotes (`'`)** or **double quotes (`"`). Both forms are functionally equivalent, but following consistent conventions makes your code more readable.

---

# Creating String Literals

Python allows you to define strings using either:

- Single quotes (`' '`)
- Double quotes (`" "`)

## Using Double Quotes

```python
message = "Hello, World!"
print(message)
```

**Output**

```text
Hello, World!
```

---

## Using Single Quotes

```python
message = 'Hello, World!'
print(message)
```

**Output**

```text
Hello, World!
```

> [!NOTE]
> There is **no functional difference** between single and double quotes in Python. Choose one style and use it consistently throughout your code.

---

# Best Practices for Quotes

Although both quote styles work the same way, Python developers generally follow these conventions.

## Use Double Quotes When the String Contains Single Quotes

```python
print("You're doing great!")
```

This avoids the need to escape the apostrophe.

---

## Use Single Quotes When the String Contains Double Quotes

```python
print('Have you read "Hamlet"?')
```

Again, this improves readability by avoiding unnecessary escape characters.

---

## Avoid Mixing Quote Styles

A string must start and end with the **same type** of quote.

### Incorrect

```python
"Hello'
```

This results in a syntax error because the opening and closing quotes do not match.

---

# Escaping Quotes

Sometimes you need to include the same quote character used to delimit the string. In such cases, use the **backslash (`\`)** before the quote.

This process is called **escaping**.

---

## Escaping Single Quotes

```python
print('You\'re doing great!')
```

**Output**

```text
You're doing great!
```

---

## Escaping Double Quotes

```python
print("Have you read \"Hamlet\"?")
```

**Output**

```text
Have you read "Hamlet"?
```

---

## Comparison

The following pairs of statements produce identical output.

### Example 1

```python
print("You're doing great!")
print('You\'re doing great!')
```

### Example 2

```python
print('Have you read "Hamlet"?')
print("Have you read \"Hamlet\"?")
```

> [!TIP]
> Prefer choosing the appropriate outer quotes instead of escaping whenever possible. It makes your code cleaner and easier to read.

---

# Multiline Strings

Normally, string literals occupy a single line.

To create a string that spans multiple lines, use **triple quotes**.

Python supports both:

- Triple double quotes (`""" """`)
- Triple single quotes (`''' '''`)

---

## Multiline String with Triple Double Quotes

```python
print("""This
is
a
multi-line
string""")
```

**Output**

```text
This
is
a
multi-line
string
```

---

## Multiline String with Triple Single Quotes

```python
print('''This
is
a
multi-line
string''')
```

**Output**

```text
This
is
a
multi-line
string
```

Both approaches produce exactly the same result.

---

# When to Use Multiline Strings

Triple-quoted strings are useful for:

- Long paragraphs of text
- SQL queries
- JSON or XML templates
- Documentation strings (docstrings)
- Preserving line breaks

Example:

```python
message = """Dear User,

Welcome to Python.

Happy Learning!
"""

print(message)
```

---

# Empty Strings

A string can also contain **no characters**.

```python
empty = ""

print(empty)
print(len(empty))
```

**Output**

```text

0
```

An empty string is still a valid string object.

---

# Common Mistakes

## Mismatched Quotes

```python
print("Hello')
```

**Result**

```text
SyntaxError
```

Always close a string with the same type of quote used to open it.

---

## Unnecessary Escaping

Instead of writing:

```python
print('You\'re learning Python')
```

Prefer:

```python
print("You're learning Python")
```

This is more readable and follows common Python style conventions.

---

# Key Takeaways

- A **string literal** is enclosed in either single (`'`) or double (`"`) quotes.
- Single and double quotes behave the same in Python.
- Use:
  - Double quotes when the string contains single quotes.
  - Single quotes when the string contains double quotes.
- Do **not** mix quote styles within the same string literal.
- Use the backslash (`\`) to **escape** quotes when necessary.
- Triple quotes (`'''` or `"""`) create **multiline strings**.
- Triple-quoted strings preserve line breaks exactly as written.
- Prefer choosing appropriate outer quotes over unnecessary escaping for better readability.
