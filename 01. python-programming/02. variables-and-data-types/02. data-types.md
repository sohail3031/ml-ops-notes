Every value in Python has a **data type**. A data type determines:

- How the value is stored in memory.
- What operations can be performed on it.
- How Python processes those operations.

Whether you're working with text, numbers, or more complex objects, understanding data types is fundamental to writing Python programs.

---

# What Is a Data Type?

A **data type** is a classification that tells Python what kind of value an object represents.

> [!NOTE]
> Every object in Python—whether it's a variable or a constant—has an associated data type.

### Real-World Analogy

Think of data types like **biological species**.

- Every dog is an individual object.
- All dogs belong to the same **type** (or species).
- Since they share the same type, they also share common characteristics and behaviors (for example, dogs can bark).

Similarly, in Python:

- Every value is an object.
- Objects that belong to the same data type support similar operations.

---

# The `str` Data Type (Strings)

A **string** represents textual data.

In Python, the string data type is called **`str`**.

Strings can be enclosed using either:

- Double quotes (`" "`)
- Single quotes (`' '`)

Both forms are equivalent.

---

## String Examples

### Double-Quoted Strings

```python
print("")               # Empty string
print("string")         # One word
print("Hello, World!")  # A sentence
```

### Output

```text

string
Hello, World!
```

> [!NOTE]
> The first `print()` displays an empty string, so the output appears as a blank line.

---

### Single-Quoted Strings

```python
print('a')                    # Single character
print('1234')                 # Sequence of digits
print('Bonjour, le monde!')   # Sentence
```

### Output

```text
a
1234
Bonjour, le monde!
```

---

## Real-World Example

Strings are commonly used to represent information such as:

- Names
- Addresses
- Messages
- Emails
- File paths
- URLs

### Example

```python
print("hello@example.com")
```

### Output

```text
hello@example.com
```

# Numeric Data Types

Python provides several numeric data types. The two most commonly used are:

- `int` — Integer numbers
- `float` — Floating-point (decimal) numbers

---

## Integer (`int`)

An **integer** is a whole number without a decimal point.

Integers can be:

- Positive
- Negative
- Zero

### Examples

```python
print(11)
print(0)
print(-5)
```

### Output

```text
11
0
-5
```

### Common Uses

- Counting objects
- Loop counters
- Age
- Number of students
- Quantity of items

---

## Floating-Point Numbers (`float`)

A **float** represents a real number that contains a decimal point.

### Examples

```python
print(11.0)
print(-1.03)
print(3.14159)
```

### Output

```text
11.0
-1.03
3.14159
```

### Common Uses

- Scientific calculations
- Measurements
- Percentages
- Financial calculations
- Statistical analysis

---

# `int` vs `float`

Although `11` and `11.0` represent the same numeric value, they belong to different data types.

| Integer (`int`) | Float (`float`) |
|-----------------|-----------------|
| `11` | `11.0` |
| No decimal point | Has a decimal point |
| Whole numbers | Decimal numbers |

> [!IMPORTANT]
> The presence of a decimal point determines whether Python treats a number as a `float`.

---

# Checking the Data Type with `type()`

Python provides the built-in `type()` function to determine the data type of any object.

## Syntax

```python
type(object)
```

---

## Checking String Types

```python
print(type("hello"))
print(type('world'))
```

### Output

```text
<class 'str'>
<class 'str'>
```

---

## Checking Integer Types

```python
print(type(100))
print(type(-50))
```

### Output

```text
<class 'int'>
<class 'int'>
```

---

## Checking Float Types

```python
print(type(3.14))
print(type(-0.5))
```

### Output

```text
<class 'float'>
<class 'float'>
```

> [!TIP]
> The `type()` function is extremely useful when debugging programs or learning Python, as it helps verify the type of any value.

---

# Key Takeaways

- Every value in Python has a **data type**.
- The three fundamental data types introduced in this lesson are:
  - `str` — Text
  - `int` — Whole numbers
  - `float` — Decimal numbers
- Strings can be enclosed in either single or double quotes.
- Integers do not contain decimal points.
- Floats always contain a decimal point.
- Use the `type()` function to determine the data type of any object.
