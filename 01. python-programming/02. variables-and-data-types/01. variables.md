Programs often need to **store**, **retrieve**, and **reuse** data while they run. In Python, this is accomplished using **variables**.

A variable acts as a **named storage location** in memory where you can keep a value and access or modify it later.

---

# What Is a Variable?

A **variable** is a named reference to a value stored in memory.

Think of a variable as a **labeled box**:

- The **label** is the variable's name.
- The **contents** of the box are the value stored in it.

Instead of remembering the value itself, you simply use the variable's name whenever you need it.

> [!NOTE]
> Variables make programs easier to read, maintain, and reuse by allowing you to store data instead of repeatedly writing the same values.

---

# Creating a Variable

A variable is created by assigning a value to it using the assignment operator (`=`).

## Syntax

```python
variable_name = value
```

According to **PEP 8** (Python's official style guide), place **one space** before and after the assignment operator.

## Example

```python
day_of_week = "Monday"
```

Here:

- `day_of_week` is the variable name.
- `"Monday"` is the value assigned to it.

---

# Accessing a Variable

Once a variable has been created, you can access its value simply by using its name.

## Example

```python
day_of_week = "Monday"

print(day_of_week)
```

### Output

```text
Monday
```

---

# Checking the Type of a Variable

Since variables store values, their data type depends on the value assigned to them.

## Example

```python
day_of_week = "Monday"

print(type(day_of_week))
```

### Output

```text
<class 'str'>
```

The variable `day_of_week` stores a **string**, so its type is `str`.

---

# Reassigning Variables

Variables are **mutable references**, meaning you can assign a new value to an existing variable at any time.

## Example

```python
day_of_week = "Monday"

day_of_week = "Tuesday"

print(day_of_week)
```

### Output

```text
Tuesday
```

After reassignment, the old value (`"Monday"`) is replaced by the new value (`"Tuesday"`).

---

# Assigning One Variable to Another

You can assign the value of one variable to another variable.

## Example

```python
a = 10
b = a

print(a)
print(b)
```

### Output

```text
10
10
```

Both variables contain the same value.

---

# Using an Undefined Variable

A variable must be defined before it can be used.

## Incorrect Example

```python
print(month_name)
```

### Output

```text
NameError: name 'month_name' is not defined
```

> [!WARNING]
> Trying to access a variable that has not been created results in a **NameError**.

---

# Dynamic Typing in Python

Python is a **dynamically typed** language.

This means a variable can reference values of different data types during program execution.

## Example

```python
month = "December"

print(type(month))
```

### Output

```text
<class 'str'>
```

Now assign an integer to the same variable.

```python
month = 12

print(type(month))
```

### Output

```text
<class 'int'>
```

The same variable now stores an integer instead of a string.

> [!IMPORTANT]
> A variable in Python is **not permanently tied to a specific data type**. Its type changes based on the value currently assigned to it.

---

# Why Avoid Excessive Type Changes?

Although Python allows changing a variable's type, doing so frequently can make code harder to understand and debug.

### Less Readable

```python
value = "100"

# Many lines later...
value = 100
```

Someone reading the code may incorrectly assume `value` is still a string.

> [!TIP]
> Whenever possible, keep a variable's data type consistent throughout your program.

---

# Variable Naming Rules

Python has specific rules for naming variables.

## Rules

### 1. Variable Names Are Case-Sensitive

```python
month = "January"
Month = "February"
```

These are **two different variables**.

---

### 2. Variable Names Must Start With

- A letter (`a-z`, `A-Z`)
- An underscore (`_`)

Valid examples:

```python
user_name = "Alice"
score1 = 95
_count = 10
```

---

### 3. Variable Names Cannot Start With a Number

❌ Invalid

```python
2score = 100
```

✅ Valid

```python
score2 = 100
```

---

### 4. Variable Names Can Contain

- Letters
- Digits
- Underscores

Example:

```python
student_age = 20
```

---

### 5. Variable Names Cannot Be Python Keywords

You cannot use reserved keywords as variable names.

❌ Invalid

```python
class = "Python"
```

Examples of Python keywords include:

- `if`
- `else`
- `for`
- `while`
- `class`
- `def`
- `return`

---

# Variable Naming Best Practices

Choose descriptive variable names that clearly indicate what they store.

### Good

```python
student_name = "John"
total_marks = 450
current_temperature = 28.5
```

### Avoid

```python
x = "John"
a = 450
temp1 = 28.5
```

> [!TIP]
> Meaningful variable names make code easier to read and maintain.

---

# Key Takeaways

- A **variable** is a named location used to store data.
- Variables are created using the assignment operator (`=`).
- Use `print()` to display a variable's value.
- Use `type()` to determine the data type of a variable.
- Variables can be reassigned with new values.
- Python supports **dynamic typing**, allowing a variable to hold different data types over time.
- Variables must be defined before they are used.
- Follow Python's naming rules and use descriptive names.
