Arithmetic operations are one of the most fundamental parts of programming. Just as we perform calculations in everyday life—such as finding the total cost of items, calculating discounts, or measuring areas—we use arithmetic operators in Python to perform similar calculations.

Python provides several built-in arithmetic operators for working with numbers.

---

# Basic Arithmetic Operators

Python supports the following arithmetic operators:

| Operator | Name | Example | Result |
|----------|------|---------|--------|
| `+` | Addition | `10 + 5` | `15` |
| `-` | Subtraction | `10 - 5` | `5` |
| `*` | Multiplication | `10 * 5` | `50` |
| `/` | Division | `10 / 5` | `2.0` |
| `//` | Integer (Floor) Division | `10 // 5` | `2` |
| `%` | Modulo (Remainder) | `10 % 3` | `1` |
| `**` | Exponentiation (Power) | `2 ** 3` | `8` |

---

# Basic Examples

```python
print(10 + 10)   # Addition
print(100 - 10)  # Subtraction
print(10 * 10)   # Multiplication
print(77 / 10)   # Division
print(77 // 10)  # Integer Division
```

### Output

```text
20
90
100
7.7
7
```

---

# Division vs Integer Division

Python provides two different division operators.

## Division (`/`)

The `/` operator **always returns a floating-point number (`float`)**, even if the result is mathematically a whole number.

```python
print(10 / 2)
```

### Output

```text
5.0
```

---

## Integer Division (`//`)

The `//` operator performs **floor division**, returning the integer part of the result by discarding the decimal portion.

```python
print(77 // 10)
```

### Output

```text
7
```

### Comparison

| Expression | Result | Data Type |
|------------|--------|-----------|
| `77 / 10` | `7.7` | `float` |
| `77 // 10` | `7` | `int` |

> [!IMPORTANT]
> Floor division does **not** round the result. It removes the fractional part by rounding **down** toward negative infinity.

---

# Division by Zero

Attempting to divide a number by zero causes Python to raise an exception.

```python
print(10 / 0)
```

### Output

```text
ZeroDivisionError: division by zero
```

The same error occurs when using:

- `/`
- `//`
- `%`

with a divisor of `0`.

# Writing Complex Expressions

Arithmetic operators can be combined to create more complex mathematical expressions.

## Example

```python
print(2 + 2 * 2)
```

### Output

```text
6
```

Multiplication has a higher precedence than addition, so `2 * 2` is evaluated first.

---

# Using Parentheses

Parentheses allow you to control the order in which operations are performed.

```python
print((2 + 2) * 2)
```

### Output

```text
8
```

Python evaluates the expression inside the parentheses before performing multiplication.

> [!TIP]
> Even when parentheses are not required, using them can make expressions easier to read.

---

# Unary Minus

The unary minus (`-`) changes the sign of a number or an expression.

## Examples

```python
print(-10)

print(-(100 + 200))

print(-(-20))
```

### Output

```text
-10
-300
20
```

# Modulo Operator (`%`)

The modulo operator returns the **remainder** after division.

## Syntax

```python
a % b
```

---

## Checking Even and Odd Numbers

A common use of the modulo operator is determining whether a number is even or odd.

```python
print(7 % 2)
print(8 % 2)
```

### Output

```text
1
0
```

- Remainder `0` → Even number
- Remainder `1` → Odd number

---

## More Examples

```python
print(4 % 4)

print(11 % 6.0)

print(55 % 77)

print(-11 % 5)

print(11 % -5)
```

### Output

```text
0
5.0
55
4
-4
```

---

## Modulo with Negative Numbers

Python follows a specific rule when negative numbers are involved:

> [!IMPORTANT]
> **The result of the modulo operation always has the same sign as the divisor.**

Examples:

```python
11 % -5
```

Result:

```text
-4
```

```python
-11 % 5
```

Result:

```text
4
```

Python internally follows the relationship:

```python
x == (x // y) * y + (x % y)
```

or equivalently,

```python
x % y == x - (x // y) * y
```

Understanding this formula explains why modulo behaves differently with negative numbers.

# Exponentiation (`**`)

The exponentiation operator raises a number to a power.

## Syntax

```python
base ** exponent
```

---

## Examples

```python
print(10 ** 2)

print(5 ** 2)

print(2 ** 3)
```

### Output

```text
100
25
8
```

---

## Practical Example

```python
side = 4

print(side ** 2)

print(side ** 3)
```

### Output

```text
16
64
```

Here:

- `side ** 2` calculates the **area of a square**.
- `side ** 3` calculates the **volume of a cube**.

---

# Operator Precedence (Order of Operations)

Python evaluates expressions according to operator precedence.

| Priority | Operator |
|----------|----------|
| 1 | `**` (Exponentiation) |
| 2 | Unary `-` |
| 3 | `*`, `/`, `//`, `%` |
| 4 | `+`, `-` |

## Example

```python
print(2 + 3 * 4)
```

Output:

```text
14
```

Equivalent to:

```python
2 + (3 * 4)
```

---

# Left-to-Right Evaluation

When operators have the **same precedence**, Python evaluates them **from left to right**.

## Example

```python
print(10 / 5 / 2)
```

### Output

```text
1.0
```

Evaluation:

```text
10 / 5 = 2.0

2.0 / 2 = 1.0
```

---

Another example:

```python
print(8 / 2 * 5)
```

### Output

```text
20.0
```

Evaluation:

```text
8 / 2 = 4.0

4.0 * 5 = 20.0
```

> [!NOTE]
> Operators with equal precedence are always evaluated from **left to right**.

# Writing Readable Expressions (PEP 8)

PEP 8 recommends placing **one space** on both sides of binary operators.

## ❌ Poor Style

```python
number=30+12
```

## ✅ Recommended Style

```python
number = 30 + 12
```

---

# Operators vs Operands

Consider the following expression:

```python
30 + 12
```

- `+` is the **operator**.
- `30` and `12` are the **operands**.

> [!NOTE]
> **Operators** perform actions, while **operands** are the values on which those actions are performed.

---

# Breaking Long Expressions

When an expression spans multiple lines, PEP 8 recommends breaking **before** binary operators (Knuth's style).

## ❌ Less Readable

```python
income = (gross_wages +
          taxable_interest +
          (dividends - qualified_dividends) -
          ira_deduction -
          student_loan_interest)
```

## ✅ Recommended

```python
income = (gross_wages
          + taxable_interest
          + (dividends - qualified_dividends)
          - ira_deduction
          - student_loan_interest)
```

This style makes operators easier to identify and improves readability.

# Key Takeaways

- Python supports:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
  - Integer Division (`//`)
  - Modulo (`%`)
  - Exponentiation (`**`)
- `/` returns a **float**.
- `//` performs floor division.
- `%` returns the remainder after division.
- `**` raises a number to a power.
- Parentheses override the default order of operations.
- Operators with the same precedence are evaluated from **left to right**.
- Follow **PEP 8** by placing spaces around binary operators.
