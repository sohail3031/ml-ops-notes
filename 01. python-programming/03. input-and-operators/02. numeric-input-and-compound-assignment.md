Many programs perform calculations based on data provided by the user. Since the `input()` function always returns a **string**, we often need to convert user input into numeric data types before performing arithmetic operations.

This lesson introduces:

- Reading numeric input
- Converting strings to numbers
- Compound assignment operators
- Counter variables

---

# Reading Numeric Input

The `input()` function always returns a string, even if the user enters a number.

To perform calculations, convert the input using:

- `int()` for integers
- `float()` for floating-point numbers

## Reading an Integer

```python
integer = int(input())
```

---

## Reading a Floating-Point Number

```python
floating_point = float(input())
```

> [!IMPORTANT]
> Never name your variables `int` or `float`. These are built-in Python functions, and using them as variable names will overwrite the original functions within the current scope.

### Good

```python
age = int(input())
price = float(input())
```

### Avoid

```python
int = 25
float = 9.99
```

---

# Invalid Numeric Input

If the entered value cannot be converted to the specified numeric type, Python raises a `ValueError`.

## Example

```python
number = int(input())
```

### Sample Input

```text
two
```

### Output

```text
ValueError: invalid literal for int() with base 10
```

> [!WARNING]
> Only use `int()` or `float()` when the input is expected to be a valid number.

# Example: Calculating Free Air Miles

Suppose a credit card rewards **2 air miles** for every dollar spent.

The following program calculates how many months are needed to earn enough miles for a round trip between London and Paris.

## Example

```python
# Average monthly spending
money = int(input("How much money do you spend per month? "))

# Miles earned per dollar
miles_per_dollar = 2

# Total miles earned each month
miles_per_month = money * miles_per_dollar

# One-way distance (London → Paris)
distance = 215

# Months required for a round trip
print((distance * 2) / miles_per_month)
```

### Explanation

1. Read the user's monthly spending.
2. Calculate the number of miles earned each month.
3. Compute the total miles required for a round trip.
4. Divide the required miles by the monthly earned miles.

> [!NOTE]
> In programming challenges (such as Hyperskill), avoid using prompt messages inside `input()` unless explicitly requested. Automated tests generally provide input directly and expect only the required output.

# Assignment Operators

The assignment operator (`=`) stores a value in a variable.

## Example

```python
number = 10
```

Python also provides **compound assignment operators**, which combine an arithmetic operation with assignment.

---

# Compound Assignment Operators

Instead of writing:

```python
number = number + 1
```

you can write:

```python
number += 1
```

Both statements produce the same result.

---

## Why Use Compound Assignment?

Compound assignment operators:

- Make code shorter.
- Improve readability.
- Avoid repeating variable names.

---

## Available Compound Assignment Operators

| Operator | Equivalent To |
|----------|---------------|
| `+=` | `x = x + y` |
| `-=` | `x = x - y` |
| `*=` | `x = x * y` |
| `/=` | `x = x / y` |
| `//=` | `x = x // y` |
| `%=` | `x = x % y` |
| `**=` | `x = x ** y` |

---

## Examples

### Addition Assignment

```python
number = 10

number += 5

print(number)
```

Output

```text
15
```

---

### Multiplication Assignment

```python
number = 6

number *= 4

print(number)
```

Output

```text
24
```

---

### Integer Division Assignment

```python
number = 20

number //= 3

print(number)
```

Output

```text
6
```

# Counter Variables

A **counter** is a variable used to keep track of how many times something happens.

Counters are commonly used in loops, although they can also be useful in many other situations.

Since counters represent counts, they are usually integers.

---

## Increasing a Counter

```python
counter = 1

step = int(input())

counter += step

print(counter)
```

### Sample Input

```text
3
```

### Output

```text
4
```

The value entered by the user is added to the counter using the `+=` operator.

---

## Ensuring Positive Input with `abs()`

Sometimes you only want non-negative values.

Python provides the built-in `abs()` function, which returns the absolute value of a number.

## Example

```python
counter = 1

step = abs(int(input()))

counter += step

print(counter)
```

### Sample Input

```text
-3
```

### Output

```text
4
```

Although the user entered `-3`, `abs()` converted it to `3`.

---

# The `abs()` Function

The `abs()` function returns the absolute (non-negative) value of a number.

## Examples

```python
print(abs(-10))

print(abs(10))

print(abs(-7.5))
```

### Output

```text
10
10
7.5
```

> [!TIP]
> `abs()` is useful whenever only the magnitude of a value matters, regardless of whether it is positive or negative.

---

# Best Practices

- Convert user input to the correct numeric type before performing calculations.
- Avoid naming variables after built-in functions such as `int`, `float`, or `abs`.
- Use compound assignment operators whenever appropriate.
- Use descriptive variable names.
- Use `abs()` when negative values should be treated as positive.

---

- `input()` always returns a string.
- Convert numeric input using:
  - `int()`
