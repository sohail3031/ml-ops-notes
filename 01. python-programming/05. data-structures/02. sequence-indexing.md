# Overview

Python provides several collection types for storing data. **Positionally ordered collections** are called **sequences**. The most common sequence types are:

- **Lists**
- **Strings**

Each element in a list and each character in a string has an **index** that represents its position.

> [!NOTE]
> Python uses **zero-based indexing**, meaning the first element is always at index `0`.

---

# Accessing Elements Using Indexes

To access an element in a sequence, use **square brackets (`[]`)** with the element's index.

## Syntax

```python
sequence[index]
```

### Example: Lists

```python
colors = ["red", "green", "blue"]

first_elem = colors[0]   # "red"
second_elem = colors[1]  # "green"
third_elem = colors[2]   # "blue"
```

### Example: Strings

```python
pet = "cat"

first_char = pet[0]   # "c"
second_char = pet[1]  # "a"
third_char = pet[2]   # "t"
```

---

# Index Rules

- The first element has index `0`.
- The last element has index `len(sequence) - 1`.

For example:

```python
colors = ["red", "green", "blue"]

print(len(colors))      # 3
print(colors[2])        # "blue"
print(colors[len(colors) - 1])  # "blue"
```

> [!TIP]
> The last valid index is always **one less than the length** of the sequence.

---

# IndexError

Attempting to access an index that does not exist raises an **`IndexError`**.

## Example

```python
colors = ["red", "green", "blue"]
pet = "cat"

print(colors[3])
# IndexError: list index out of range

print(pet[3])
# IndexError: string index out of range
```

> [!WARNING]
> Always ensure that the index is within the valid range:
>
> - `0` to `len(sequence) - 1` (positive indexing)
> - `-len(sequence)` to `-1` (negative indexing)

---

# Mutable vs Immutable Sequences

## Lists are Mutable

List elements can be modified using their indexes.

```python
colors = ["red", "green", "blue"]

colors[1] = "white"

print(colors)
# ['red', 'white', 'blue']
```

---

## Strings are Immutable

Strings **cannot** be modified after they are created.

```python
pet = "cat"

pet[0] = "b"

# TypeError: 'str' object does not support item assignment
```

> [!IMPORTANT]
> - **Lists** → Mutable ✅
> - **Strings** → Immutable ❌

---

# Negative Indexing

Python allows accessing elements from the **end** of a sequence using **negative indexes**.

| Index | Element |
|-------:|---------|
| `-1` | Last element |
| `-2` | Second last element |
| `-3` | Third last element |
| ... | ... |
| `-len(sequence)` | First element |

---

## Example: Lists

```python
colors = ["red", "green", "blue"]

last_elem = colors[-1]      # "blue"
second_elem = colors[-2]    # "green"
first_elem = colors[-3]     # "red"
```

---

## Example: Strings

```python
pet = "cat"

last_char = pet[-1]     # "t"
second_char = pet[-2]   # "a"
first_char = pet[-3]    # "c"
```

> [!TIP]
> Negative indexing is especially useful when you need the last few elements without knowing the sequence length.

---

# Invalid Negative Indexes

Using a negative index outside the valid range also raises an **`IndexError`**.

```python
pet = "cat"

print(pet[-4])

# IndexError: string index out of range
```

---

# Positive vs Negative Indexing

For the list:

```python
colors = ["red", "green", "blue"]
```

| Positive Index | Element | Negative Index |
|--------------:|---------|---------------:|
| `0` | `"red"` | `-3` |
| `1` | `"green"` | `-2` |
| `2` | `"blue"` | `-1` |

---

# Common Errors

## `IndexError`

Occurs when accessing an index that does not exist.

```python
numbers = [10, 20, 30]

print(numbers[3])

# IndexError: list index out of range
```

---

## `TypeError`

Occurs when trying to modify a string.

```python
text = "Python"

text[0] = "J"

# TypeError: 'str' object does not support item assignment
```

---

# Key Takeaways

- A **sequence** is an ordered collection of elements.
- **Lists** and **strings** are sequences.
- Python uses **zero-based indexing**.
- Access elements using **square brackets (`[]`)**.
- The last positive index is `len(sequence) - 1`.
- Negative indexing starts from the end:
  - `-1` → Last element
  - `-2` → Second last element
- Lists are **mutable**.
- Strings are **immutable**.
- Accessing an invalid index raises an **`IndexError`**.
- Modifying a string raises a **`TypeError`**.
