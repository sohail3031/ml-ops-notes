# What is a List?

A **list** is an **ordered collection** of items.

Lists allow you to store multiple values in a single variable.

Example:

```python
dog_breeds = ['corgi', 'labrador', 'poodle', 'jack russell']

print(dog_breeds)
```

Output:

```text
['corgi', 'labrador', 'poodle', 'jack russell']
```

---

# Creating Lists

## Using Square Brackets `[]`

The most common way to create a list.

```python
numbers = [1, 2, 3, 4, 5]

print(numbers)
```

Output:

```text
[1, 2, 3, 4, 5]
```

---

## Using the `list()` Function

The `list()` function creates a list from an **iterable**.

Example:

```python
letters = list("danger!")

print(letters)
```

Output:

```text
['d', 'a', 'n', 'g', 'e', 'r', '!']
```

Each character becomes a separate list element.

---

## Non-Iterable Objects

`list()` only works with iterable objects.

Example:

```python
list(235)
```

Output:

```text
TypeError: 'int' object is not iterable
```

An integer is **not iterable**.

---

# `list()` vs `[]`

These two examples produce different results.

Using `list()`:

```python
letters = list("danger!")

print(letters)
```

Output:

```text
['d', 'a', 'n', 'g', 'e', 'r', '!']
```

---

Using square brackets:

```python
word = ["danger!"]

print(word)
```

Output:

```text
['danger!']
```

### Difference

|Code|Result|
|---|---|
|`list("danger!")`|Multiple elements (one character per element)|
|`["danger!"]`|One element containing the entire string|

---

# Creating Empty Lists

Using `list()`:

```python
empty_list = list()
```

Using square brackets:

```python
empty_list = []
```

Both create:

```text
[]
```

---

# Features of Lists

## 1. Ordered

Lists preserve the order of elements.

```python
fruits = ["apple", "banana", "orange"]

print(fruits)
```

Output:

```text
['apple', 'banana', 'orange']
```

The order remains the same.

---

## 2. Iterable

Lists can be processed one element at a time.

Example:

```python
numbers = [1, 2, 3]
```

You will later use loops to iterate through them.

---

## 3. Allow Duplicate Values

Lists can store repeated values.

```python
states = ["on", "off", "on", "off", "on"]

print(states)
```

Output:

```text
['on', 'off', 'on', 'off', 'on']
```

Duplicates are perfectly valid.

---

## 4. Can Store Different Data Types

A list can contain different kinds of objects.

```python
mixed = [
    "Python",
    10,
    3.14,
    True,
    [1, 2, 3]
]

print(mixed)
```

Output:

```text
['Python', 10, 3.14, True, [1, 2, 3]]
```

A list can contain:

- Strings
    
- Integers
    
- Floats
    
- Booleans
    
- Other lists
    

---

# Nested Lists

Lists can contain other lists.

Example:

```python
matrix = [
    [1, 2],
    [3, 4]
]

print(matrix)
```

Output:

```text
[[1, 2], [3, 4]]
```

---

# Finding the Length of a List

Use the built-in `len()` function.

Syntax:

```python
len(list_name)
```

---

## Example

```python
numbers = [1, 2, 3, 4, 5]

print(len(numbers))
```

Output:

```text
5
```

---

## Empty List

```python
empty = []

print(len(empty))
```

Output:

```text
0
```

---

## Single Element List

```python
single = ["danger!"]

print(len(single))
```

Output:

```text
1
```

---

## List Created from a String

```python
letters = list("danger!")

print(len(letters))
```

Output:

```text
7
```

Each character counts as a separate element.

# Common Mistakes

## Confusing `list()` and `[]`

Incorrect expectation:

```python
list("Python")
```

Output:

```text
['P', 'y', 't', 'h', 'o', 'n']
```

If you wanted one element:

```python
["Python"]
```

Output:

```text
['Python']
```

---

## Using `list()` on a Non-Iterable

```python
list(100)
```

Produces:

```text
TypeError
```

Use:

```python
[100]
```

if you want a list containing one integer.

# Key Takeaways

- A **list** is an ordered collection of values.
- Lists are created using `[]` or the `list()` function.
- `list()` converts an **iterable** (such as a string) into a list.
- Lists:
    - Preserve order
    - Are iterable
    - Allow duplicate values
    - Can store different data types, including other lists
- Use `len()` to find the number of elements in a list.
- Remember the difference between:
    - `["Python"]` → one element
    - `list("Python")` → multiple character elements
