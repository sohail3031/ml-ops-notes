The **Boolean** data type is used to represent values that have only **two possible states**, such as:

- Yes / No
- True / False
- On / Off
- Open / Closed

Booleans are essential in programming because they allow programs to make decisions, control program flow, and evaluate conditions.

---

# The Boolean Data Type (`bool`)

Python provides a built-in Boolean data type called `bool`.

A Boolean value can be one of only two values:

- `True`
- `False`

> [!IMPORTANT]
> `True` and `False` **must** begin with a capital letter. Writing `true` or `false` results in a `NameError` because Python treats them as variable names.

---

## Example

```python
is_open = True
is_closed = False

print(is_open)
print(is_closed)
```

### Output

```text
True
False
```

---

# Boolean Variables

Boolean variables are commonly used to represent states.

## Examples

```python
is_logged_in = True

is_admin = False

door_open = True

game_over = False
```

Using meaningful variable names makes code easier to understand.

# Logical Operators

Python provides three logical (Boolean) operators:

| Operator | Type | Description |
|----------|------|-------------|
| `and` | Binary | Returns `True` if **both** operands are `True`. |
| `or` | Binary | Returns `True` if **at least one** operand is `True`. |
| `not` | Unary | Reverses (negates) a Boolean value. |

---

# The `and` Operator

The `and` operator returns `True` **only when both operands are `True`.**

## Truth Table

| Left | Right | Result |
|------|-------|--------|
| `True` | `True` | `True` |
| `True` | `False` | `False` |
| `False` | `True` | `False` |
| `False` | `False` | `False` |

---

## Example

```python
print(True and True)

print(True and False)

print(False and False)

print(False and True)
```

### Output

```text
True
False
False
False
```

---

# The `or` Operator

The `or` operator returns `True` if **at least one operand is `True`.**

## Truth Table

| Left | Right | Result |
|------|-------|--------|
| `True` | `True` | `True` |
| `True` | `False` | `True` |
| `False` | `True` | `True` |
| `False` | `False` | `False` |

---

## Example

```python
print(True or True)

print(True or False)

print(False or False)

print(False or True)
```

### Output

```text
True
True
False
True
```

---

# The `not` Operator

The `not` operator is a **unary operator**, meaning it operates on only one value.

It simply reverses the Boolean value.

## Example

```python
to_be = True

not_to_be = not to_be

print(not_to_be)
```

### Output

```text
False
```

---

# Operator Precedence

Logical operators are evaluated according to the following precedence:

| Priority | Operator |
|----------|----------|
| 1 | `not` |
| 2 | `and` |
| 3 | `or` |

---

## Example

```python
print(False or not False)
```

### Evaluation

```text
False or True
```

### Output

```text
True
```

> [!TIP]
> When in doubt, use parentheses to make expressions easier to read.

---

# Truthy and Falsy Values

Python allows non-Boolean values to be used in Boolean expressions.

These values are categorized as either:

- **Truthy**
- **Falsy**

---

## Falsy Values

The following values evaluate to `False`:

| Value | Description |
|--------|-------------|
| `False` | Boolean false |
| `None` | Null value |
| `0` | Integer zero |
| `0.0` | Floating-point zero |
| `""` | Empty string |
| `[]` | Empty list |
| `{}` | Empty dictionary |
| `()` | Empty tuple |
| `set()` | Empty set |

Everything else is generally considered **truthy**.

---

# Truthy Examples

```python
print(bool(1))

print(bool(-5))

print(bool("Python"))

print(bool([1, 2, 3]))
```

### Output

```text
True
True
True
True
```

---

# Falsy Examples

```python
print(bool(0))

print(bool(""))

print(bool([]))

print(bool(False))
```

### Output

```text
False
False
False
False
```

---

# Logical Operators with Non-Boolean Values

Python's logical operators work with any objects that can be evaluated as truthy or falsy.

## Example

```python
print(0.0 or False)

print("True" and True)

print("" or False)
```

### Output

```text
False
True
False
```

# `and` and `or` Return Operands

Unlike many programming languages, Python's `and` and `or` operators **do not always return `True` or `False`.**

Instead, they return one of their operands.

---

## `and` Behavior

```python
x and y
```

- Returns **`x`** if `x` is falsy.
- Otherwise returns **`y`**.

### Examples

```python
print(False and True)

print(True and True)

print(True and False)
```

### Output

```text
False
True
False
```

---

## Example with Truthy Values

```python
result = False or 5 and 100

print(result)
```

### Evaluation

```text
5 and 100
```

Both values are truthy.

`and` returns the **second operand**:

```text
100
```

Now:

```text
False or 100
```

`or` returns the first truthy value:

```text
100
```

### Output

```text
100
```

> [!IMPORTANT]
> `and` and `or` return operands—not necessarily Boolean values.

---

## `or` Behavior

```python
x or y
```

- Returns **`x`** if `x` is truthy.
- Otherwise returns **`y`**.

### Examples

```python
print(True or False)

print(False or True)

print(False or False)
```

### Output

```text
True
True
False
```

---

# Using Parentheses

Parentheses change the order of evaluation.

## Example

```python
tricky = not (False or "")

print(tricky)
```

### Evaluation

```text
False or ""
```

Both values are falsy.

The expression evaluates to:

```text
""
```

Applying `not`:

```text
not ""
```

results in:

```text
True
```

### Output

```text
True
```

# Short-Circuit Evaluation

Python's logical operators use **short-circuit evaluation** (also called **lazy evaluation**).

This means Python stops evaluating an expression as soon as the final result is already known.

---

## Short-Circuit with `or`

```python
result = True or (1 / 0)
```

Since the first operand is already `True`, Python never evaluates:

```python
1 / 0
```

### Result

```text
True
```

No error occurs.

---

## Short-Circuit with `and`

```python
result = False and (1 / 0)
```

Since the first operand is already `False`, the second expression is never evaluated.

### Result

```text
False
```

Again, no error occurs.

> [!NOTE]
> Short-circuit evaluation improves both performance and safety by avoiding unnecessary computations.
