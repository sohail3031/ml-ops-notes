As programs become more complex, they contain multiple lines of code instead of just one. Python executes these statements **from top to bottom**, one line at a time.

In this lesson, you'll learn how to print multiple lines of text using the `print()` function.

---

# Printing Multiple Lines

The simplest way to print multiple lines is to use multiple `print()` statements.

## Example

```python
print("I")
print("know")
print("Python")
```

### Output

```text
I
know
Python
```

Each call to `print()` displays its output on a **new line**.

> [!NOTE]
> Every `print()` statement automatically moves the cursor to the next line after printing its output.

---

# Printing an Empty Line

The `print()` function can also be used without any arguments to print a blank line.

## Example

```python
print("I")
print()
print("know")
print("")
print("Python")
```

### Output

```text
I

know

Python
```

Both of the following statements produce the same result:

```python
print()
```

```python
print("")
```

### Difference

- `print()` prints a blank line without any arguments.
- `print("")` prints an empty string, which also results in a blank line.

From the user's perspective, both produce identical output.

> [!TIP]
> Although both approaches work, `print()` is generally preferred when you simply want to insert a blank line.

---

# Blank Lines in Code

Leaving empty lines **between statements in your source code** does **not** affect the program's output.

## Example

```python
print("And")

print("you?")
```

### Output

```text
And
you?
```

The blank line in the code is ignored by Python.

> [!IMPORTANT]
> Empty lines in your code are used only to improve **readability**. They do **not** create blank lines in the program's output.

---

# Key Takeaways

- Use multiple `print()` statements to display multiple lines of output.
- Each `print()` call automatically starts a new line.
- `print()` prints a blank line.
- `print("")` also prints a blank line because it prints an empty string.
- Empty lines in your source code do **not** affect the program's output.

---

# Summary

Python executes code one statement at a time. To print multiple lines, simply use multiple `print()` statements. If you need to insert a blank line in the output, use `print()` (or `print("")`). Remember that blank lines in your source code are ignored during execution and are only meant to improve code readability.
