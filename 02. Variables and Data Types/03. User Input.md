Most real-world programs need to **interact with users**. They often ask users to provide information, process that information, and then display a result.

Python provides the built-in `input()` function to read input from the user.

---

# The `input()` Function

The `input()` function waits for the user to type a value and press **Enter**. It then returns the entered value as a **string**.

## Syntax

```python
input()
```

---

# Reading User Input

The simplest way to use `input()` is to store the user's input in a variable.

## Example

```python
user_name = input()

print("Hello, " + user_name)
```

### Sample Input

```text
SAM
```

### Output

```text
Hello, SAM
```

### Explanation

1. `input()` waits for the user to enter a value.
2. The entered value is stored in the variable `user_name`.
3. `print()` displays a greeting using the entered name.

---

# Displaying a Prompt Message

It's good practice to tell users what information they should enter.

The `input()` function accepts an optional prompt message.

## Example

```python
user_name = input("Please enter your name: ")

print("Hello, " + user_name)
```

### Sample Interaction

```text
Please enter your name: SAM
Hello, SAM
```

> [!TIP]
> Using a prompt makes programs more user-friendly because users immediately know what input is expected.

---

# Printing the Prompt Separately

Instead of passing a message directly to `input()`, you can print it beforehand.

## Example

```python
print("Enter your name:")

user_name = input()

print("Hello, " + user_name)
```

### Sample Interaction

```text
Enter your name:
SAM
Hello, SAM
```

### Difference

| Prompt Inside `input()` | Prompt Using `print()` |
|--------------------------|------------------------|
| User types on the same line as the prompt. | User types on the next line. |

Both approaches are correct.

> [!NOTE]
> In coding challenges (such as those on Hyperskill), avoid displaying prompt messages unless explicitly required. Automated tests typically expect only the requested output.

---

# How `input()` Works

When Python reaches an `input()` statement:

1. Program execution pauses.
2. The program waits for the user to enter a value.
3. The user presses **Enter**.
4. The entered value is returned.
5. Program execution continues.

> [!IMPORTANT]
> The program will remain paused until the user presses **Enter**.

---

# `input()` Always Returns a String

Regardless of what the user types, `input()` always returns a value of type `str`.

## Example

```python
value = input()

print(type(value))
```

### Sample Input

```text
25
```

### Output

```text
<class 'str'>
```

Even though the user entered a number, Python treats it as a string.

---

# Converting Input to an Integer

If you need numeric input, convert the string using `int()`.

## Example

```python
print("What's your favorite number?")

value = int(input())
```

### Sample Input

```text
42
```

The variable `value` now stores the integer `42`.

---

# Invalid Integer Input

If the entered value cannot be converted to an integer, Python raises an exception.

## Example

```python
age = int(input())
```

### Sample Input

```text
hello
```

### Output

```text
ValueError: invalid literal for int() with base 10
```

> [!WARNING]
> Use `int()` only when you're sure the user will enter a valid integer.

---

# Reading Multiple Inputs

To read multiple values, call `input()` multiple times.

## Example

```python
day = int(input())

month = input()
```

### Sample Input

```text
4
October
```

Now you can use both values later in the program.

```python
print("Cinnamon Roll Day is celebrated on", month, day)
```

### Output

```text
Cinnamon Roll Day is celebrated on October 4
```

# Common Input Patterns

## Reading Text

```python
name = input()
```

---

## Reading an Integer

```python
age = int(input())
```

---

## Reading a Floating-Point Number

```python
price = float(input())
```

---

## Reading Multiple Values (One Per Line)

```python
name = input()

age = int(input())

salary = float(input())
```

---

# Best Practices

- Always provide clear prompts in user-facing applications.
- Convert input to the appropriate data type when needed.
- Use meaningful variable names.
- Remember that `input()` always returns a string.

---

# Key Takeaways

- `input()` reads input from the keyboard.
- The function pauses execution until the user presses **Enter**.
- The returned value is always a **string (`str`)**.
- Use:
  - `int()` to convert input to an integer.
  - `float()` to convert input to a floating-point number.
- Call `input()` multiple times to read multiple values.
- Prompt messages improve user experience but should usually be omitted in automated coding challenges.

---

# Summary

The `input()` function allows Python programs to interact with users by accepting keyboard input. Since all input is returned as a string, you often need to convert it to the appropriate data type before performing calculations. Understanding how `input()` works is essential because nearly every interactive Python program relies on user input.
