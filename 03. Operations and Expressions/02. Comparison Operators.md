Comparison operators allow you to compare two values and determine their relationship. The result of every comparison is always a **Boolean** value:

- `True`
- `False`

Comparison operators are commonly used in:

- Conditional statements (`if`, `elif`, `else`)
- Loops
- Filtering data
- Validating user input

---

# Comparison Operators

Python provides the following comparison operators:

| Operator | Meaning |
|----------|---------|
| `<` | Less than |
| `<=` | Less than or equal to |
| `>` | Greater than |
| `>=` | Greater than or equal to |
| `==` | Equal to |
| `!=` | Not equal to |
| `is` | Object identity |
| `is not` | Negated object identity |
| `in` | Membership |
| `not in` | Negated membership |

> [!NOTE]
> This lesson focuses on the first six comparison operators:
>
> - `<`
> - `<=`
> - `>`
> - `>=`
> - `==`
> - `!=`

---

# Comparing Integers

Comparison operators compare two values and return either `True` or `False`.

## Example

```python
a = 5
b = -10
c = 15

print(a < b)
print(a == a)
print(a != b)
print(b >= c)
```

### Output

```text
False
True
True
False
```

---

# Comparing Expressions

You can compare expressions, not just variables.

## Example

```python
a = 5
b = -10
c = 15

result = a == b + c

print(result)
```

### Evaluation

```text
5 == (-10 + 15)

5 == 5
```

### Output

```text
True
```

# Combining Comparisons

Since comparisons return Boolean values, they can be combined using logical operators.

## Example

```python
x = -5
y = 10
z = 12

result = x < y and y <= z

print(result)
```

### Output

```text
True
```

---

# Comparison Chaining

Python supports **comparison chaining**, which makes comparisons more concise and readable.

Instead of writing:

```python
x < y and y <= z
```

you can write:

```python
x < y <= z
```

Both expressions are equivalent.

---

## Example

```python
x = -5
y = 10
z = 12

print(x < y <= z)
```

### Output

```text
True
```

---

## Another Example

```python
print(10 < (100 * 100) <= 10000)
```

### Evaluation

```text
10 < 10000 <= 10000
```

### Output

```text
True
```

> [!TIP]
> Chained comparisons evaluate the middle expression only **once**, making them more efficient and easier to read.

---

# Comparison Operator Precedence

Comparison operators have:

- Lower precedence than arithmetic operators.
- Higher precedence than logical operators (`and`, `or`).

For example:

```python
print(5 + 3 > 6)
```

Python first evaluates:

```python
5 + 3
```

Then compares:

```python
8 > 6
```

### Output

```text
True
```

---

# Complex Comparison Chaining

Comparison chaining can sometimes become difficult to read.

## Example

```python
a = 1
b = 2
c = 3
e = 4
f = 5
g = 6

print(b + c <= e or f + g >= e == f == 5)

print((b + c <= e or f + g >= e) == (f == 5))
```

### Output

```text
False
True
```

---

## Understanding the First Expression

```python
b + c <= e or f + g >= e == f == 5
```

Python evaluates it as:

```python
(b + c <= e) or ((f + g >= e) and (e == f) and (f == 5))
```

Step by step:

```text
2 + 3 <= 4
5 <= 4
False
```

Next:

```text
11 >= 4
True
```

Then:

```text
4 == 5
False
```

Since one part of the chained comparison is `False`, the entire chained comparison becomes `False`.

Finally:

```text
False or False
```

Result:

```text
False
```

# Logical Operators with Comparisons

Remember that Python's logical operators are **short-circuit operators**.

Because of this, expressions may return values other than `True` or `False`.

---

## Example 1

```python
a = 1
b = 2
c = 3
e = 4
f = 5
g = 6

print(b + c * f >= e and (f + g) * c)
```

### Evaluation

```text
2 + 3 × 5 = 17

17 >= 4
True
```

Expression becomes:

```python
True and 33
```

The `and` operator returns the second operand.

### Output

```text
33
```

---

## Example 2

```python
print((f + g) * c and b + c * f >= e)
```

Evaluation:

```text
33 and True
```

Since the first operand is truthy, `and` returns the second operand.

### Output

```text
True
```

---

## Example 3

```python
print(b + c * f <= e and (f + g) * c)
```

Evaluation:

```text
17 <= 4
False
```

Expression becomes:

```python
False and 33
```

Short-circuit evaluation stops immediately.

### Output

```text
False
```

---

## Example 4

```python
print((f + g) * c and b + c * f <= e)
```

Evaluation:

```text
33 and False
```

### Output

```text
False
```

---

## Example 5

```python
print(b + c * f >= e or (f + g) * c)
```

Evaluation:

```text
True or 33
```

Since the first operand is already truthy, Python never evaluates the second operand.

### Output

```text
True
```

---

## Example 6

```python
print((f + g) * c or b + c * f >= e)
```

Evaluation:

```text
33 or True
```

Since `33` is truthy, `or` returns it immediately.

### Output

```text
33
```

---

## Example 7

```python
print((f + g) * c or b + c * f <= e)
```

### Output

```text
33
```

---

## Example 8

```python
print(b + c * f <= e or (f + g) * c)
```

Evaluation:

```text
False or 33
```

### Output

```text
33
```

---

# Why Does This Happen?

Recall how logical operators behave:

### `and`

Returns:

- The **first falsy** operand, or
- The **last operand** if all operands are truthy.

### `or`

Returns:

- The **first truthy** operand, or
- The **last operand** if all operands are falsy.

This is why logical expressions don't always return `True` or `False`.

# Best Practices

- Prefer comparison chaining when appropriate.

```python
# Good
10 < age < 60

# Less readable
10 < age and age < 60
```

- Use parentheses for complex expressions.

```python
(a > b) and (c < d)
```

- Avoid overly complicated chained comparisons, as they can reduce readability.

---

# Key Takeaways

- Comparison operators compare two values and always produce a Boolean result.
- The six basic comparison operators are:
  - `<`
  - `<=`
  - `>`
  - `>=`
  - `==`
  - `!=`
- Comparisons can be combined using logical operators.
- Python supports **comparison chaining**, which is more concise and evaluates intermediate expressions only once.
- Arithmetic operations are evaluated before comparisons.
- Logical operators (`and` and `or`) may return operands instead of Boolean values because of **short-circuit evaluation**.
- Parentheses improve readability in complex expressions.

Comparison operators are fundamental for making decisions in Python programs. They allow you to compare values, combine multiple conditions, and create expressive logical statements. Python's comparison chaining and short-circuit evaluation make code concise and efficient, but understanding operator precedence and return values is essential for writing clear, bug-free programs.
