When working with objects that have complex structures, such as large dictionaries or lists containing multiple values, you may need to preserve their structure for storage or transfer. This process is known as **serialization**.

Ideally, the serialization format should have simple syntax and be easy for humans to read. One popular format that meets these requirements is **YAML**.

## What Is YAML?

**YAML** is a recursive acronym for **YAML Ain't Markup Language**.

It is a human-readable data serialization format that can be used across different programming languages. YAML is commonly used for:

- Configuration files
- Storing structured data 
- Transferring data between systems

YAML is widely used in software configuration, especially in tools and platforms such as Kubernetes, Docker Compose, CI/CD pipelines, and many other development tools.

The most common file extensions are:

- `.yaml`
- `.yml`

In this topic, we will cover YAML's basic data types, data structures, syntax, and comments.

## Basic Data Types

YAML supports common data types such as numbers, strings, booleans, and null values. It can also recognize certain specialized types, such as dates, timestamps, and special numerical values.

The basic YAML data types include:

- **Integers** — `15`, `123`
- **Strings** — `"15"`, `'Hello, YAML!'`
- **Floats** — `15.033`
- **Booleans** — `true`, `false`
- **Null** — `null`

### Type Detection

YAML automatically detects the type of a value based on its content.

For example:

```yaml
number: 15
boolean: true
empty_value: null
```

However, you can explicitly specify a type using `!!`.

For example, to explicitly treat `yes` as a string:

```yaml
value: !!str yes
```

Here, `!!str` explicitly specifies that the value should be interpreted as a string.

## Maps

A **map** is a collection of key-value pairs.

For example:

```yaml
---
object: Book

metadata:
  name: Three Men in a Boat
  author: Jerome K. Jerome
  genre: humorous account

published:
  year: 1889
  country: United Kingdom
```

### Understanding the Syntax

The first line:

```yaml
---
```

is a YAML **document start marker**.

It is optional when a file contains a single YAML document, but it is useful when defining multiple YAML documents in the same file.

The remaining content consists of `key: value` pairs.

For example:

```yaml
object: Book
```

In this example:

- `object` is the **key**
- `Book` is the **value**

YAML uses a clean syntax and does not usually require symbols such as:

- Curly braces `{ }`
- Square brackets `[ ]`
- Closing tags
- Quotation marks

However, quotation marks can still be used when necessary.

> [!important]  
> YAML indentation must use **spaces**, not tabs. Indentation is significant because it defines the structure and hierarchy of the data.

## Lists

A **list** in YAML is a sequence of values.

For example:

```yaml
animals:
  - cat
  - dog
  - bird
```

Each item in a block-style YAML list begins with a hyphen (`-`).

The general structure is:

```yaml
parent:
  - item1
  - item2
  - item3
```

There is no fixed limit on the number of items in a YAML list.

### Flow Style

YAML also supports a compact representation called **flow style**.

The previous list can be written as:

```yaml
animals: [cat, dog, bird]
```

## Combining Maps and Lists

Maps and lists can be combined to create more complex data structures.

For example, you can have:

- Maps containing other maps
- Maps containing lists
- Lists containing lists
- Lists containing maps

Consider the following example, where a map contains nested maps and lists:

```yaml
weekend:
  saturday:
    - order cleaning
    - order a pizza
    - watch a new series
  sunday:
    - go to yoga
    - hang out with a friend
```

Here:

- `weekend` is a map.
- `saturday` and `sunday` are nested keys.
- Each day contains a list of activities.

## Multiline Strings

If you want to represent multiple lines of text as a single string while preserving line breaks, use the pipe character (`|`).

For example:

```yaml
saturday: |
  order cleaning
  order a pizza
  watch a new series
```

This creates a single multiline string while preserving the newline characters.

> [!note]  
> A block starting with `|` represents a multiline string, not a YAML list.

## Comments

Comments can be added to YAML files using the `#` character.

A comment continues until the end of the line.

For example:

```yaml
# This is a comment

metadata: # This is metadata
  name: Three Men in a Boat
  author: Jerome K. Jerome
  genre: humorous account
```

Comments can be placed:

- On their own line
- After a YAML value or key-value pair

Comments are ignored when YAML data is parsed.

## YAML Syntax Summary

|Feature|Syntax|Example|
|---|---|---|
|Key-value pair|`key: value`|`name: Sohail`|
|List item|`- value`|`- Python`|
|Nested data|Indentation|`user:` followed by indented values|
|Flow-style list|`[value1, value2]`|`[cat, dog, bird]`|
|Multiline string|`\|`|`message: \|`|
|Comment|`#`|`# This is a comment`|
|Explicit type|`!!type`|`!!str yes`|
|Document start|`---`|`---`|

## Key Points

- **YAML** is a human-readable, text-based data serialization format.
- YAML is commonly used for configuration files and structured data.
- Common YAML file extensions are `.yaml` and `.yml`.
- YAML supports data types such as integers, strings, floats, booleans, and `null`.
- YAML primarily uses **maps** and **lists** to organize data.
- Maps and lists can be nested and combined to create complex structures.
- YAML uses **spaces for indentation**, and tabs should not be used.
- The `|` character can be used to create multiline strings while preserving line breaks.
- Comments begin with `#` and continue until the end of the line.
