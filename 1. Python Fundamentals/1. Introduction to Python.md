# What is Python?

Python was created by **Guido van Rossum** and first released in **1991**. It is designed with a strong emphasis on **readability** and **simplicity**, allowing developers to write clear and concise code.

The name **Python** was inspired by the British comedy television show **Monty Python's Flying Circus**, reflecting the creator's goal of making programming enjoyable and accessible.

## Why Learn Python?

Python is beginner-friendly while also being powerful enough for professional software development. It has a simple syntax that closely resembles the English language, making it easier to learn than many other programming languages.

### Common Applications of Python

- **Web Development**
  - Build websites and backend APIs.
  - Popular frameworks:
    - Django
    - Flask
    - FastAPI

- **Data Science & Machine Learning**
  - Analyze data and build machine learning models.
  - Popular libraries:
    - NumPy

- **Artificial Intelligence (AI)**
  - Develop AI-powered applications.
  - Work with Large Language Models (LLMs) and other AI technologies.

- **Automation & Scripting**
  - Automate repetitive tasks.
  - Build internal tools.
  - Orchestrate workflows.

# Your First Python Program

The traditional first program in almost every programming language is **Hello, World!**

```python
print("Hello, world!")
```

### Output

```text
Hello, world!
```

You can replace the text inside `print()` with any message you want.

# Taking Input from the User

Python provides the built-in `input()` function to accept input from the user.

## Example

```python
age = input("How old are you? ")
print("I know that you're " + age + " years old.")
```

### Sample Output

```text
How old are you? 21
I know that you're 21 years old.
```

> [!NOTE]
> The `input()` function always returns the entered value as a **string**.

# Python Uses Indentation

Unlike many programming languages that use braces (`{}`) to define code blocks, Python uses **indentation**.

Indentation is mandatory and determines which statements belong to a particular block of code.

## Example

```python
age = int(input("How old are you? "))

if age > 18:
    print("You're an adult.")
else:
    print("You're a minor.")
```

> [!IMPORTANT]
> The original example compared the result of `input()` directly with the number `18`, which is incorrect because `input()` returns a string.
>
> Converting the input using `int()` allows a proper numeric comparison.

# Comments in Python

Comments are used to explain code and improve readability. They are ignored by the Python interpreter.

A single-line comment begins with the `#` symbol.

## Example

```python
# Define a function that acts like a parrot.
# It repeats whatever the user enters.
def parrot():
    answer = input()
    print(answer)

# Call the function.
parrot()
```

Comments are useful for:

- Explaining complex logic
- Making code easier to understand
- Leaving notes for yourself or other developers
