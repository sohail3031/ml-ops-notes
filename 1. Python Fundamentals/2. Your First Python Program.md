# The "Hello, World!" Program

The **Hello, World!** program is traditionally used to introduce beginners to a new programming language.

## Example

```python
print("Hello, World!")
```

### Output

```text
Hello, World!
```

This program consists of a single line of code. The `print()` function displays the text provided inside the parentheses. The quotation marks are used to define the string but are **not** displayed in the output.

---

# Understanding the Code

Let's break down the program into its components.

## The `print()` Function

`print()` is a built-in Python function used to display output on the screen.

Functions are reusable blocks of code that perform a specific task. Whenever a function name is followed by parentheses `()`, it means the function is being **called** (executed).

### Syntax

```python
print(value)
```

The value passed inside the parentheses is called an **argument**.

---

## Strings in Python

A **string** is a sequence of characters enclosed in either:

- Double quotes (`" "`)
- Single quotes (`' '`)

Both of the following examples are valid:

```python
print("Hello, World!")
```

```python
print('Hello, World!')
```

You can replace the string with any text you want.

### Example

```python
print("Python 3.x")
```

### Output

```text
Python 3.x
```

---

# Printing Quotes Inside Strings

Sometimes the text you want to print already contains quotation marks or an apostrophe.

## Using Double Quotes

If the string contains a single quote (`'`), surround the entire string with **double quotes**.

### Example

```python
print("Yes, I'm ready to learn Python.")
```

### Output

```text
Yes, I'm ready to learn Python.
```

Since the string is enclosed in double quotes, the apostrophe in **I'm** is treated as part of the text.

---

## Incorrect Example

The following code is invalid:

```python
print('Yes, I'm ready to learn Python.')
```

Python interprets the apostrophe in **I'm** as the end of the string, resulting in a syntax error.

> [!WARNING]
> Always ensure that the opening and closing quotation marks match correctly.

# Common Beginner Errors

Even simple programs can contain mistakes. Below are some of the most common errors.

---

## 1. Extra Indentation

### Incorrect

```python
    print("Hello, World!")
```

Python does not allow unexpected indentation.

> [!WARNING]
> Avoid adding unnecessary spaces or tabs at the beginning of a line.

---

## 2. Misspelling a Function Name

### Incorrect

```python
pint("Hello, World!")
```

The correct function name is:

```python
print("Hello, World!")
```

> [!TIP]
> Python recognizes functions only by their exact names.

---

## 3. Incorrect Letter Case

Python is **case-sensitive**, which means uppercase and lowercase letters are treated differently.

### Incorrect

```python
PRINT("All caps")
```

### Correct

```python
print("All caps")
```

> [!IMPORTANT]
> `print`, `Print`, and `PRINT` are considered three different identifiers in Python.

---

## 4. Missing Quotation Marks

### Incorrect

```python
print("Python)
```

The closing quotation mark is missing, resulting in a syntax error.

### Correct

```python
print("Python")
```

---

## 5. Missing Parentheses

### Incorrect

```python
print("I have no end"
```

The closing parenthesis is missing.

### Correct

```python
print("I have no end")
```

---

# Best Practices

- Always use the correct function name.
- Match opening and closing quotation marks.
- Match opening and closing parentheses.
- Pay attention to letter case.
- Avoid unnecessary indentation.

---

# Key Takeaways

- `print()` is used to display output.
- A **string** is text enclosed in single or double quotes.
- Functions are called using parentheses `()`.
- Python is **case-sensitive**.
- Matching quotation marks and parentheses is essential.
- Small syntax mistakes can prevent a program from running.
