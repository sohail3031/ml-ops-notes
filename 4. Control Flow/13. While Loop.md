Loops allow a program to execute the same block of code **multiple times**. Instead of writing repetitive code, you can use a loop to automate repeated tasks.

One of Python's most fundamental loops is the **`while` loop**.

A `while` loop continues executing as long as a specified condition remains `True`.

---

# What is a `while` Loop?

A `while` loop repeatedly executes a block of code **while its condition evaluates to `True`**.

Once the condition becomes `False`, the loop stops, and the program continues with the next statement.

---

# Syntax

```python
while condition:
    # code to execute
```

### Components

- `while` → Keyword that starts the loop.
- `condition` → A Boolean expression evaluated before each iteration.
- `:` → Marks the beginning of the loop body.
- **Indentation** → Defines the statements that belong to the loop.

> [!IMPORTANT]
> The loop condition is checked **before** each iteration. If the condition is `False` initially, the loop body will **never execute**.

---

# How a `while` Loop Works

The execution flow of a `while` loop is:

1. Evaluate the condition.
2. If the condition is `True`, execute the loop body.
3. Return to the condition.
4. Repeat until the condition becomes `False`.
5. Continue with the rest of the program.

---

# Example

```python
number = 0

while number < 5:
    print(number)
    number += 1

print("Now, the number is equal to 5")
```

### Output

```text
0
1
2
3
4
Now, the number is equal to 5
```

# Counter Variable

A **counter** is a variable whose value changes during each iteration.

In most `while` loops, the counter determines when the loop should stop.

Example:

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

Output:

```text
1
2
3
4
5
```

> [!TIP]
> Always ensure the counter is updated inside the loop. Otherwise, the loop may never end.

---

# Infinite Loop

An **infinite loop** occurs when the loop condition **never becomes `False`**.

## Example

```python
number = 0

while number < 5:
    print(number)
```

Since `number` is never increased, the condition:

```python
number < 5
```

always remains `True`.

The program repeatedly prints:

```text
0
0
0
0
0
...
```

and continues forever.

---

# Fixing an Infinite Loop

Always update the variable involved in the loop condition.

```python
number = 0

while number < 5:
    print(number)
    number += 1
```

Now the loop terminates correctly.

---

# Intentional Infinite Loops

Sometimes infinite loops are intentional.

A common example is a program that continuously waits for user input or processes incoming requests.

Python allows this by using:

```python
while True:
    # continuously execute code
```

Since `True` is always true, the loop never ends unless it is explicitly terminated.

Example:

```python
while True:
    print("Running forever...")
```

This loop continues until:

- the program is manually stopped, or
- a `break` statement is executed (covered later).

---

# Common Mistakes

## Forgetting to Update the Counter

```python
count = 1

while count <= 5:
    print(count)
```

This creates an infinite loop.

---

## Incorrect Condition

```python
count = 5

while count < 5:
    print(count)
```

Output:

```text
(no output)
```

The condition is already `False`, so the loop never executes.

---

## Incorrect Indentation

```python
count = 0

while count < 5:
print(count)
```

This results in an:

```text
IndentationError
```

Remember that Python uses indentation to define the loop body.

---

# Best Practices

- Use meaningful variable names.

```python
attempt = 0

temperature = 25

score = 100
```

- Always update the loop variable if the condition depends on it.
- Keep loop conditions simple and easy to understand.
- Avoid accidental infinite loops.
- Use comments when the loop logic is complex.

---

# Key Takeaways

- A `while` loop repeats a block of code **while a condition remains `True`**.
- The condition is evaluated **before every iteration**.
- If the condition is initially `False`, the loop body never executes.
- Counter variables are commonly used to control the number of iterations.
- Forgetting to update the counter can create an **infinite loop**.
- `while True:` creates an intentional infinite loop that must be terminated manually or with a `break` statement.

---

# Summary

The `while` loop is a fundamental looping construct in Python that repeatedly executes code based on a Boolean condition. By using a counter variable and updating it correctly, you can control how many times the loop runs. Understanding `while` loops is essential before moving on to more advanced topics such as `for` loops, `break`, `continue`, and nested loops.
