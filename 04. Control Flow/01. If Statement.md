Programs often need to make decisions based on certain conditions. In Python, this is done using the **`if` statement**.

An `if` statement executes a block of code **only if** a specified condition evaluates to `True`.

---

# Syntax of an `if` Statement

The basic syntax is:

```python
if condition:
    # code to execute
```

### Components

- `if` → Keyword that starts the conditional statement.
- `condition` → A Boolean expression that evaluates to either `True` or `False`.
- `:` → A colon marks the beginning of the code block.
- **Indentation** → The block of code inside the `if` statement must be indented.

> [!IMPORTANT]
> Python uses **indentation** to define code blocks instead of braces `{}`. The standard indentation is **4 spaces**, as recommended by **PEP 8**.

---

# Simple `if` Statement

## Example

```python
biscuits = 17

if biscuits >= 5:
    print("It's time for tea!")
```

### Output

```text
It's time for tea!
```

### Explanation

The condition:

```python
biscuits >= 5
```

evaluates to:

```python
17 >= 5
```

which is:

```text
True
```

Since the condition is `True`, Python executes the indented block.

---

# When the Condition is False

If the condition evaluates to `False`, the indented block is skipped.

## Example

```python
biscuits = 3

if biscuits >= 5:
    print("It's time for tea!")

print("Program finished.")
```

### Output

```text
Program finished.
```

The first `print()` statement is skipped because the condition is false.

---

# Code Blocks and Indentation

All lines with the same indentation belong to the same block.

## Example

```python
biscuits = 17

if biscuits >= 5:
    print("It's time for tea!")
    print("What tea do you prefer?")

print("What about some chocolate?")
```

### Output

```text
It's time for tea!
What tea do you prefer?
What about some chocolate?
```

### Explanation

Since the condition is `True`, both indented lines execute.

The final `print()` statement is **outside** the `if` block, so it always executes.

---

## Example with a False Condition

```python
biscuits = 2

if biscuits >= 5:
    print("It's time for tea!")
    print("What tea do you prefer?")

print("What about some chocolate?")
```

### Output

```text
What about some chocolate?
```

# Boolean Conditions

The condition in an `if` statement must evaluate to a Boolean value (`True` or `False`).

Most commonly, conditions use comparison operators.

## Example

```python
age = 20

if age >= 18:
    print("You are an adult.")
```

---

You can also use Boolean variables directly.

```python
is_logged_in = True

if is_logged_in:
    print("Welcome!")
```

---

# Common Mistake: `=` vs `==`

A very common beginner mistake is confusing:

- Assignment operator (`=`)
- Equality operator (`==`)

### Correct

```python
if age == 18:
    print("Exactly 18!")
```

### Incorrect

```python
if age = 18:
    print("Exactly 18!")
```

The second example causes a **SyntaxError** because `=` is used for assignment, **not comparison**.

> [!WARNING]
> Use:
>
> - `=` → Assign a value.
> - `==` → Compare two values.

---

# Nested `if` Statements

An `if` statement can contain another `if` statement.

This is called a **nested `if`**.

## Syntax

```python
if condition1:
    if condition2:
        # code
```

The inner `if` executes **only if** the outer condition is already `True`.

---

# Example

```python
rainbow = "red, orange, yellow, green, blue, indigo, violet"
warm_colors = "red, yellow, orange"
my_color = "orange"

if my_color in rainbow:
    print("Wow, your color is in the rainbow!")

    if my_color in warm_colors:
        print("Oh, by the way, it's a warm color.")
```

### Output

```text
Wow, your color is in the rainbow!
Oh, by the way, it's a warm color.
```

---

# Understanding the Example

First Python checks:

```python
my_color in rainbow
```

Since `"orange"` exists in the `rainbow` string, the condition is `True`.

Python enters the first block and prints:

```text
Wow, your color is in the rainbow!
```

Next, it checks:

```python
my_color in warm_colors
```

Again, the condition is `True`, so Python prints:

```text
Oh, by the way, it's a warm color.
```

---

# The `in` Operator

The `in` operator checks whether a value exists within another object.

## Example

```python
print("apple" in "apple banana orange")

print("grape" in "apple banana orange")
```

### Output

```text
True
False
```

The `in` operator returns a Boolean value, making it suitable for use in `if` statements.

---

# Indentation in Nested `if` Statements

Each nested block requires an additional level of indentation.

## Example

```python
if True:
    print("Level 1")

    if True:
        print("Level 2")

        if True:
            print("Level 3")
```

### Output

```text
Level 1
Level 2
Level 3
```

---

# Best Practices

- Use **4 spaces** for indentation.
- Keep conditions simple and readable.
- Avoid deeply nested `if` statements whenever possible.
- Use meaningful variable names.
- Use `==` for comparisons and `=` for assignments.

---

# Key Takeaways

- The `if` statement executes code only when its condition is `True`.
- Every `if` statement ends with a colon (`:`).
- Python uses **indentation** to define code blocks.
- Conditions must evaluate to a Boolean value.
- Comparison operators (`==`, `>`, `<`, `>=`, etc.) are commonly used in conditions.
- Do not confuse:
  - `=` (assignment)
  - `==` (comparison)
- Nested `if` statements allow multiple levels of decision-making.
- The `in` operator checks membership and returns a Boolean value.

---

# Summary

The `if` statement is one of the most fundamental control structures in Python. It allows programs to execute code conditionally based on Boolean expressions. Understanding indentation, comparison operators, and nested `if` statements is essential before moving on to more advanced control flow structures such as `if-else`, `elif`, loops, and functions.
