## What is an `if-else` Statement?

An **if-else statement** allows a program to choose between **two different blocks of code** based on a condition.

- If the condition is **True**, the `if` block executes.
- If the condition is **False**, the `else` block executes.

Only **one** of the two blocks is executed.

---

# Syntax

```python
if condition:
    # Code executed if condition is True
else:
    # Code executed if condition is False
```

- `if` requires a condition.
- `else` does **not** require a condition.
- A colon (`:`) follows both `if` and `else`.
- Code blocks are defined using **4-space indentation**.

---

# Basic Example

```python
today = "holiday"

if today == "holiday":
    print("Lucky you!")
else:
    print("Keep your chin up, then.")
```

Output:

```text
Lucky you!
```

---

## Another Example

```python
age = 16

if age >= 18:
    print("You can vote.")
else:
    print("You are too young to vote.")
```

Output:

```text
You are too young to vote.
```

---

# How `if-else` Works

Flow of execution:

```text
          Condition
             │
      ┌──────┴──────┐
      │             │
   True          False
      │             │
   if block     else block
      │             │
      └──────┬──────┘
             │
      Continue program
```

---

# Ternary Operator (One-Line If-Else)

Python provides a shorter way to write simple `if-else` statements.

### Syntax

```python
value_if_true if condition else value_if_false
```

---

## Example

```python
sun = True

print("It's daytime!" if sun else "It's nighttime!")
```

Output:

```text
It's daytime!
```

---

## Another Example

```python
age = 20

status = "Adult" if age >= 18 else "Minor"

print(status)
```

Output:

```text
Adult
```

---

## When to Use the Ternary Operator

✅ Good for:

- Simple conditions
- Assigning values
- Short, readable code

❌ Avoid for:

- Complex logic
- Multiple conditions
- Long expressions

Example (hard to read):

```python
# Avoid
result = "A" if x > 0 and y < 10 and z == 5 else "B"
```

---

# Nested `if-else`

An `if-else` statement can contain another `if-else` inside it.

Example:

```python
x = 100

if x < 100:
    print("x < 100")
else:
    if x == 100:
        print("x = 100")
    else:
        print("x > 100")

    print("This runs because x >= 100")
```

Output:

```python
x = 100
This runs because x >= 100
```

---

# Understanding the Nested Example

For `x = 100`:

1. Check `x < 100`
    - `False`
2. Enter the `else` block.
3. Check `x == 100`
    - `True`
4. Print:

```python
x = 100
```

5. Continue inside the outer `else` block:

```python
This runs because x >= 100
```

---

# Indentation Matters

Correct:

```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

Incorrect:

```python
if age >= 18:
print("Adult")
else:
print("Minor")
```

This raises an **IndentationError**.

---

# `if` vs `if-else`

|`if`|`if-else`|
|---|---|
|Executes code only when the condition is `True`.|Chooses between two alternatives.|
|May execute nothing if the condition is `False`.|Always executes one of the two blocks.|
|No alternative action.|Includes an alternative action using `else`.|

Example:

```python
# if only
if score >= 50:
    print("Passed")
```

If `score < 50`, nothing happens.

```python
# if-else
if score >= 50:
    print("Passed")
else:
    print("Failed")
```

Now, one message is always printed.

---

# Best Practices

- Use **4 spaces** for indentation.
- Keep conditions simple and readable.
- Use the ternary operator only for short expressions.
- Avoid deeply nested `if-else` statements when possible, as they reduce readability.

---

# Common Mistakes

### ❌ Forgetting the colon

```python
if age >= 18
```

✅ Correct

```python
if age >= 18:
```

---

### ❌ Incorrect indentation

```python
if age >= 18:
print("Adult")
```

✅ Correct

```python
if age >= 18:
    print("Adult")
```

---

### ❌ Adding a condition after `else`

```python
else age >= 18:
```

✅ Correct

```python
else:
```

`else` never has a condition.

---

# Key Takeaways

- `if-else` chooses between **two alternative code blocks**.
- The `if` block runs when the condition is `True`.
- The `else` block runs when the condition is `False`.
- Only **one** block executes.
- `else` never takes a condition.
- Python supports a **ternary operator** for concise one-line `if-else` expressions:

```python
value_if_true if condition else value_if_false
```

- `if-else` statements can be nested, but excessive nesting should be avoided for better readability.
